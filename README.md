# رسـالتي | Resalti ❤️

> **لما يعجز الكلام، خلّي رسالتي تتكلم.**
> *When words fail, let Resalti speak.*

تطبيق ويب يساعدك على قول ما تشعر به: تدخل اسم الشخص، المناسبة، مشاعرك، الأسلوب وبعض التفاصيل، فيحوّلها إلى رسالة طبيعية وشخصية يمكنك تعديلها ونسخها وحفظها ومشاركتها.

A production-shaped web app (not a mock-up): real generation, real editing, real copy/save/share, three languages, RTL, light/dark, mobile-first, and an AI layer that can be swapped without touching the UI.

---

## التشغيل السريع · Quick start

```bash
npm install
npm run dev        # API on :4000 + web on :5173 (web proxies /api → API)
```

البناء والتشغيل كخدمة واحدة:

```bash
npm run build
npm start          # serves the built app + the API from http://0.0.0.0:4000
```

الاختبارات:

```bash
npm test           # 30 tests: the AI engine + a jsdom run of the real React app
```

التطبيق يعمل **بدون أي مفتاح API** — يستخدم المحرك المحلي المدمج. لربط نموذج حقيقي، انسخ `.env.example` إلى `.env` وضع المفتاح هناك (يبقى على الخادم فقط).

## البنية · Architecture

```
shared/ai/            ← طبقة الذكاء الاصطناعي (مشتركة بين الخادم والمتصفح)
  catalog.js            كل الخيارات: المناسبة، الشعور، الأسلوب، اللغة…
  schema.js             تنظيف والتحقق من كل مدخل + العقد المُرسل للنموذج
  prompt.js             الـ Prompt الداخلي بكل قواعد الكتابة
  localEngine.js        المحرك المحلي (يولّد نصًا حقيقيًا، ليس نصًا عشوائيًا)
  banks.js              بنوك الجمل لكل لغة/لهجة
  dialect.js            تحويل الدارجة الجزائرية ⇄ الفصحى

server/
  index.js              Express: /api/generate, /api/health + الملفات المبنية
  ai/openaiProvider.js  أي endpoint متوافق مع OpenAI (المفتاح لا يغادر الخادم)

src/
  pages/                Home, Compose, SayIt, WhatToSay, MyLetters, Ideas, Settings, Privacy, About
  components/           NavBar, LetterCard, Toast, ui primitives, Icons (SVG مضمّن)
  context/              Settings (اللغة/المظهر/حجم الخط), Letters (الرسائل المحفوظة)
  hooks/useLetterSession.js  آلة الحالة المشتركة وراء كل شاشة تُنتج رسالة
  lib/                  api (مع fallback محلي), storage, router (hash router خفيف)
  i18n/                 العربية / الفرنسية / الإنجليزية
  styles/index.css      نظام تصميم واحد بـ CSS tokens (بدون مكتبات واجهة)

tests/
  engine.test.js        22 اختبارًا للمحرك وقواعد الكتابة والـ prompt
  ui.test.mjs           تشغيل التطبيق الحقيقي داخل jsdom (Vite SSR transform)
```

### طبقة AI قابلة للتبديل

| المزوّد | متى يُستخدم | أين المفتاح |
| --- | --- | --- |
| OpenAI-compatible (`server/ai/openaiProvider.js`) | عند وجود `RESALTI_API_KEY` | الخادم فقط |
| المحرك المحلي (`shared/ai/localEngine.js`) | بدون مفتاح، أو عند فشل المزوّد، أو بدون اتصال | لا يحتاج مفتاحًا |

كلاهما يستقبل **نفس** الطلب المنظَّف من `schema.js` ويستجيب **بنفس** الشكل، لذا استبدال المحرك لا يمسّ الواجهة. الواجهة نفسها تحمل نسخة من المحرك المحلي كـ fallback (chunk منفصل يُحمَّل عند الحاجة فقط).

## الميزات · Features

- **مولّد الرسائل** (§4–§15): الاسم + خيار "لا تذكر الاسم"، اللقب، صفة مميزة، ذكرى، إلى من تكتب (8 خيارات)، المناسبة (12)، المشاعر (11، اختيار متعدد)، الأسلوب (9)، درجة العاطفة (1–5)، الطول، اللغة/اللهجة (5)، تفاصيل حرة.
- **بطاقة الرسالة**: نسخ · إعادة صياغة · أقصر · أطول · أكثر عفوية · أكثر رومانسية · أكثر نضجًا · أكثر تأثيرًا · ترجمة · رسالة أخرى · حفظ · مشاركة · تعديل مباشر للنص.
- **"حوّل كلامي إلى رسالة"** (`/say-it`): يرتّب كلامك دون تغيير معناه.
- **"ماذا أقول؟"**: رسالة مقترحة + كيف أبدأ + ماذا أتجنب + خيار آخر، مع تركيز على التواصل المحترم لا التلاعب.
- **"خصص الرسالة أكثر ✨"**: يستعمل كل التفاصيل المتاحة ويرفع درجة العاطفة.
- **اقتراحات التحسين** بعد كل رسالة، وكلها تعيد صياغة **نفس** الرسالة بدل توليد واحدة عشوائية.
- **رسائلي**: حفظ محلي فقط (لا يُحفظ شيء إلا بطلب صريح)، مع فتح/نسخ/تعديل/حذف.
- **أفكار للرسائل**: 10 تصنيفات بأفكار أصلية قصيرة، بضغطة تنتقل إلى المولّد.
- **الإعدادات**: اللغة، المظهر (فاتح/داكن/حسب الجهاز)، حجم النص، حذف البيانات، الخصوصية، حول التطبيق.

## الخصوصية · Privacy

- لا تُنشر الرسائل ولا تُشارك ولا تُعرض للعامة.
- الرسائل المحفوظة في `localStorage` على جهازك فقط.
- لا حسابات، لا كلمات مرور، لا بريد، لا معلومات مالية، **لا نظام دفع**.
- مفاتيح الذكاء الاصطناعي تُقرأ في `server/index.js` فقط ولا تُرسل إلى المتصفح.
- لا analytics ولا إعلانات ولا cookies تتبّع.
- المحرك مقيَّد بقواعد تمنع الضغط العاطفي والتلاعب واحترام حدود الطرف الآخر.

## قواعد الكتابة المضمّنة في المحرك

الكتابة بشكل طبيعي · عدم تكرار الاسم (مرتان كحد أقصى، أو صفر إن طُلب) · الحفاظ على تفاصيل المستخدم · **عدم اختراع ذكريات** · عدم تغيير معنى كلام المستخدم · تجنّب العبارات المبتذلة · مطابقة المناسبة · احترام الحدود الشخصية · منع أساليب التلاعب والضغط العاطفي.

`tests/engine.test.js` يتحقق من هذه القواعد فعليًا (مثلًا: أن الذكرى لا تظهر إن لم يذكرها المستخدم، وأن الاسم لا يتكرر أكثر من مرتين، وأن "أقصر" أقصر فعلًا مع الحفاظ على تفاصيل المستخدم).
